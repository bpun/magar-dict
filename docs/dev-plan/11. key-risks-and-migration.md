Risk	                                Mitigation
-------------------------------------------------------------------------------------------------------------
Little digital Magar data	            Partner with community groups, start with a small verified set, grow in batches
AI invents grammar or words	            Ground prompts in verified data, schema validation, admin review before publishing
Guests see unverified content	        Status filter enforced in the query layer, covered by API tests
Privilege escalation	                Single RBAC dependency, permission matrix test, last-admin guard, audit log
Token theft	                            Short access tokens, refresh rotation with reuse detection, HttpOnly cookies
AI cost overrun	                        Per-user quotas, caching, cost dashboard, budget alert at 80%
Dialect disagreement	                Label the dialect on every page, allow community feedback on each entry
Copyright of source data	            Source and license recorded per entry, unpermitted sources blocked by validation
Font or script rendering issues	        Test Devanagari on Android and iOS early, self-host the font
Data loss	                            Daily backups, tested restore, migrations that can be reversed
